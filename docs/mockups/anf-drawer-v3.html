Summary

1Task title editable — click title / ✎, rename inline; code line rebuilds, activity logs “Renamed”.

2Colours — Branch chips purple, Room chips orange.

3Group headers editable — always shown with ✎, even when there's only the default “Sub-tasks”.

4Report = 💬 icon per sub-task with a count badge (photos counted too). Tap to open the thread + input under the row. Name click no longer toggles it — less accidental opening.

5Link PR / PO — replaces “＋ Request items” with a picker: search open requests and POs, choose “whole task” or a sub-task, link. “＋ New request…” stays at the bottom. Each linked order gets ✕ unlink.

Is ⑤ a good idea? — yes, with two rules

  • Purchasing often already made the PR/PO before R&D asks — linking avoids duplicate requests. 👍
  • Link at request level. A PO can carry items for several tasks, so picking a PO links its requests (you can untick ones not for this task). Keeps “one request → one task” clean.
  • A request already linked to another task shows as “linked to …” and can be moved, not double-linked.
  • No new SQL — uses the anf_task_id / anf_subtask_id columns you just added.
