THE THREE NEW FIELDS
  • Lost reason (required) + optional note: asked when a lead is moved to Lost, by dialog or drag.
  • Lead source on new leads: LINE OA · Website · Repeat client · Referral · Agency · Instagram/FB · Other. Optional on old leads; shown as a chip on the card.
  • Stage history: the date every lead changes status and every job changes stage. Invisible to users; it starts counting from deploy day and powers funnel / on-time charts later.
