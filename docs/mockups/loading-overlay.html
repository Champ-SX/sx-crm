How it behaves
• The page layout (header, tabs, empty cards/table) shows right away underneath; a soft dim + slight blur covers it, with a centred card: the CRM loading animation (spinner shown here as a stand-in) + “Loading sales… / tasks… / requests…”.
• Appears only if loading takes over ~0.15 s, fades in/out (150 ms), so fast loads never flash.
• A dims only the page area — the sidebar stays usable, so you can switch page while waiting (recommended). B dims the whole window.
• Clicks under the overlay are blocked while it's showing. Works in dark mode (darker dim).
