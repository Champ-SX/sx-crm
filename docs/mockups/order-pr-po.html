Order board — Purchase Requests (PR) → Purchase Orders (PO)

PR = a group of items for one project (Won job or free-text). No approval step. Create PO splits PR lines by supplier; the PO document is then created in FlowAccount via API. Lines stay linked to both, and receiving a PO line still tops up stock / asset units. Sample data.
