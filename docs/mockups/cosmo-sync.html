RULES

  • Never overwrites our fields automatically. Differences are flagged; copying is a manual tap.
  • Hidden: HOLD bookings and any row without a job #. A Cosmo job # with no Won card in our CRM is listed in a small “Unmatched (n)” link next to Sync now.
  • Window: the API only returns today → +30 days; older jobs keep their last synced data.
  • Security: key stays server-only (COSMO_API_KEY); the browser only reads our own copy of the data.
  • Not included: crew list (Cosmo doesn't expose it) — staff assignment stays in our staff pill.
