Notes on requests and POs

Two kinds of note: one for the whole request and one per item. Both show to Champ when approving and to Nice on the PO. Notes are internal; the PO's own note is what Nice writes for the supplier. Sample data. Purple outline = new.

HOW IT WORKS
  • Request note: a box under the request name. Delivery, contact, why it's needed.
  • Item note: tap ＋ note under the item name. Spec, colour, size, brand.
  • Both are optional, and editable only while the request is a Draft.
  • After Submit they lock like the items. Withdraw to edit unlocks them.
  • Every change goes to the request's History.

ON THE PO
  • Notes from requests: one line per request that has a note, with its REQ number. Nothing is retyped.
  • Item notes stay under each item, with the REQ the line came from.
  • Yellow = internal. Shown in the app only, never copied to what goes to the supplier.
  • PO note: Nice's own note for the supplier (the field already exists, now shown).
