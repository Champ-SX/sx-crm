NOTES

  • Data: funnel and stage times come from the stage history recording since deploy. First reply uses existing activity notes (already recorded), so that one can show sooner.
  • On time = the job moved to “พร้อมออกงาน” at least 1 day before the event date. The goal line (90%) can be changed.
  • Who sees: Sales sees their own funnel + reply speed; Operation sees on-time + where jobs wait; Admin sees all, by person.
  • No new SQL: it uses the stage_history table from the current build.
