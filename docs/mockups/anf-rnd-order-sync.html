How it works
  • Link: a request can point to an A&F task and (optionally) one sub-task. Made from the sub-task, it's linked automatically; in Requests, “For → A&F task” picks one.
  • Needed by defaults to the sub-task's due date minus 2 days.
  • ETA: when the buyer marks a PO ordered, ETA = order date + supplier lead time (from the supplier link), editable on the PO.
  • Sub-task status: while a linked request isn't fully received the pill shows Waiting parts (teal). On receive it returns to Doing and R&D gets a notification.
  • Late warning: red when ETA (or needed-by + lead time, if not ordered yet) is after the sub-task due date. Shown on the sub-task, the card and the Timeline.
  • Activity: requested, approved, ordered (with ETA) and received are logged on the task automatically.
  • Timeline: “Show orders” draws each order from ordered → ETA under its sub-task.

  • Sub-tasks on the Timeline: show sub-task rows under each task (needed for order lines), or only the task bar with order diamonds on it?

  • On receive: just notify R&D, or also auto-tick the sub-task Done?
  • Which types can link: only R&D, or any A&F task (e.g. ลงเฟรม needing printed materials)?
