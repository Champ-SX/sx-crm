คู่มือจัดซื้อ (Purchasing) · 1 หน้า

เมนู Purchasing (จัดซื้อ) · ทุกการซื้อเริ่มจาก “คำขอ (Request)” เสมอ · ต่ำกว่า ฿10,000 อนุมัติอัตโนมัติ · ตั้งแต่ ฿10,000 ขึ้นไป คุณแชมป์อนุมัติ · ผู้สั่งซื้อหลักคือแอดมิน

ขั้นตอนทั้งหมด

① ขอซื้อทุกคน
→
② อนุมัติอัตโนมัติ / คุณแชมป์
→
③ สั่งซื้อ (PO)แอดมิน
→
④ รับของใครก็ได้ที่อยู่หน้างาน

ฉันอยากจะ…

ทุกคน

สั่งของที่ใกล้หมด

  1. เมนู Stock & Assets → หาของที่ขึ้น LOW / OUT
  2. กด Reorder → ระบบใส่ของ ผู้ขาย และราคาให้
  3. ใส่จำนวน · ตรวจราคา → กด Submit →

ถ้าขึ้น “● Requested” แปลว่ามีคนขอไปแล้ว ไม่ต้องขอซ้ำ

ทุกคน

ขอซื้อของใช้ทั่วไป (เช่น เทปผ้า)

  1. เมนู Requests → + New request
  2. เลือก General · พิมพ์ว่าขอเพื่ออะไร เช่น “เทป & เคเบิลไทร์ ทีมอีเวนต์”
  3. ค้นหาของ หรือพิมพ์ชื่อใหม่แล้วกด Enter · ใส่จำนวนและราคา
  4. กด Submit →

ราคารวม VAT · ถ้าถึง ฿10,000 ปุ่มจะเปลี่ยนเป็น “Send for approval”

คุณแชมป์

อนุมัติคำขอ

  1. กระดิ่ง 🔔 “asks for approval” หรือ Requests → แท็บ Wait for approval
  2. ดูรายการ → Approve ✓ หรือ Reject… (ต้องใส่เหตุผล)

คำขอที่รออนุมัติจะถูกล็อก ถ้าผู้ขออยากแก้ ให้กด “Withdraw to edit”

แอดมิน (ผู้สั่งซื้อ)

สั่งซื้อ (ทำ PO)

  1. กระดิ่ง 🔔 “ready to order” · Requests → แท็บ To order
  2. ติ๊กคำขอ → Create PO → (ระบบแยก PO ตามผู้ขาย)
  3. สั่งกับผู้ขาย / ทำ PO ใน FlowAccount → เมนู POs → Mark ordered →
ทุกคน

ของมาส่ง (รับของ)

  1. เมนู POs → เปิด PO → Receive… ทีละรายการ หรือ Receive all ✓
  2. ใส่จำนวนที่ได้รับจริง · ถ้าไม่ครบ เลือก “รอส่วนที่เหลือ” หรือ “ปิดยอด (Close short)”

สต็อกคลังเพิ่มอัตโนมัติ · กล้อง/อุปกรณ์จะได้รหัส เช่น CAM-007

ฉุกเฉิน

ต้องสั่งเอง แอดมินติดต่อไม่ได้

  1. เปิดคำขอที่ อนุมัติแล้ว → กดลิงก์แดง Emergency order…
  2. ใส่เหตุผล → Continue → Create PO → Mark ordered

PO จะติดป้าย EMERGENCY · คุณแชมป์และแอดมินได้รับแจ้ง

สถานะหมายถึงอะไร

Draftยังไม่ได้ส่ง แก้ไขได้
Wait for approvalรอคุณแชมป์อนุมัติ (฿10,000 ขึ้นไป)
Approved · to orderอนุมัติแล้ว รอแอดมินสั่ง
Orderedสั่งกับผู้ขายแล้ว รอของมา
Partly receivedได้รับของบางส่วน
Receivedได้รับครบแล้ว
Rejectedไม่อนุมัติ ดูเหตุผล แก้แล้วส่งใหม่ได้

คำถามที่พบบ่อย

หาของไม่เจอ? เมนู Catalog → พิมพ์ชื่อ รหัส หรือชื่อเล่น (เช่น “4x6”) · ไม่มีจริง ๆ ให้พิมพ์ชื่อใหม่ในคำขอแล้วกด “＋ Save to catalog” ราคาไม่ตรง? แก้ได้ตอนเป็น Draft เท่านั้น · ส่งแล้วกด Withdraw to edit อยากรู้ว่าใครทำอะไร? เปิดคำขอ → ดู History ด้านล่าง ขอเพิ่มหลังอนุมัติ? ทำคำขอใหม่ (ของที่อนุมัติแล้วจะถูกล็อก)
