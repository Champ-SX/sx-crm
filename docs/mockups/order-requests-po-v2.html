Create in FlowAccount sends supplier + items + VAT + project ref and stores FlowAccount's PO number/link; print / email the PO from FlowAccount. Receiving is ticked on the request or the PO — both update the same items → stock / asset units.

WHAT CHANGES FOR STAFF

  • Quick refill — exactly like today (＋Order on a LOW/OUT item). It just shows as a 1-item request.
  • Project purchase — ＋ New request (or Import Excel) → add many items → Create PO.
  • Ordering — tick requests → Create PO → Create in FlowAccount.
  • Receiving — tick received qty on the request (or PO) → stock / asset units update, as now.
  • Existing orders — each becomes a 1-item request; history kept.
