How it works
• Every card on the Sales dashboard becomes clickable (Unassigned shown here; same for Captures, True… and for each gateway card) → opens a list of exactly the payments that make up that number, for the month / filters on screen.
• Top: split by gateway with the source file name. Each row shows Thai date & time, machine (+ raw code from the file), gateway, transaction ID, channel, amount, and source file + row number so you can find it in the original Excel.
• Unusual amounts are highlighted (much higher than that machine's normal price) — like the two ChillPay rows.
• Filter by gateway or search; total at the top always equals the card's number.
• Row ↗ opens it in Review (assign machine / exclude). Export downloads these rows for checking — internal file, not a client report.
