How it works
  • Project = big task with a type: R&D OPS MKT. It moves Idea → Planned → In progress → Review → Done.
  • Sub-tasks each have an owner, due date and status (To do / Doing / Done). Progress % = done sub-tasks. Sub-tasks also show in each person's "Mine".
  • Status updates: Ops posts On track / At risk / Blocked + a short note. The latest one shows on the card, so the board is the weekly report.
  • Graphics: designers upload Frame / GIF / Welcome screen to the project. Files stay in Google Drive; the CRM keeps type, name, Drive link and status. Each goes Draft → Approved → Live at branches. Tiles show a type icon (no thumbnails, Drive files are private). The Graphics tab answers "what's live where".
  • Templates: "New campaign" pre-fills the usual sub-tasks (brief, design frame, GIF, welcome, approve, upload per branch, post).
Existing cards: moved automatically, nothing lost
  • New → Idea / Backlog · In progress → In progress · Waiting → In progress + status “Blocked” with the waiting reason as the note · Solved → Done.
  • Card detail stays the same: type, branch/room, dates, assignees, details, activity log on the right. Checklists become Sub-tasks (same items, now with owner + due).
  • Types (ลงเฟรม, R&D, Content / PR…) stay as the colour tag. Issue level / area only show on old issue-type cards.
