CAPTURES.DESIGNER as its own app

SX-CRM keeps a small Artwork section on each Won job. All design work happens in a separate Designer app that shares the same login and database. Sample data.

1 · HOW THE TWO APPS CONNECT

SX-CRM

sx-crm.vercel.app
  • Owns jobs, customers, dates, branches
  • Card shows Artwork status + thumbnail
  • “Open in Designer ↗” · Approve
  • Bell shows Designer notifications
→ /job/:idopens the right job
← status + fileswritten back to the job
← notification“Artwork ready to review”

Designer

designer.sx-crm.vercel.app
  • Owns artwork items, versions, files
  • Full-screen workspace per job
  • Reads job details (never edits them)
  • Own Vercel project · deploy any time
Same Supabase project · same Google sign-in · won_jobs (CRM) ↔ won_artwork_items (Designer)

WHAT STAYS IN SX-CRM
  • One Artwork tab: overall status, progress, the latest thumbnail and the list of deliverables.
  • Open in Designer ↗ opens the same job in the Designer app (new tab, already signed in).
  • The board card gets a tiny chip: AW 3/5, red when the event is ≤3 days away and not all approved.
  • No editing here: the CRM stays light and fast.
  • Jobs without artwork show “No artwork yet · Start in Designer ↗”.
