  • Matches on: same cleaned company + contact name, or the same phone (digits only, +66 → 0), or the same email. Checked as you type, against customers already loaded — no extra server call.
  • Lead form: “Use this” links the lead to the existing record and closes the new-contact panel. Creating anyway is still allowed with one click — it's a warning, not a block.
  • Customer form: Create stays disabled until you either open a match or choose “create new anyway” (stronger, because this form only creates customers).
  • Placeholders like “#(ลูกค้าไม่แจ้ง)” and phone “0” are ignored, so they never trigger a warning.
