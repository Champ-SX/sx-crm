6 · RULES

  • Buyer: admin@sixsheet.me, set up like the approver (champ@sixsheet.me). One buyer, no back-up.
  • Buyer only (normal): Create PO, add to a draft PO, Mark ordered, Cancel PO.
  • Anyone: request, receive (count deliveries), view everything.
  • Emergency (anyone): needs a reason. Only for approved requests. The PO is tagged EMERGENCY and Champ and the buyer get a bell notification.
  • Buyer notified every time a request becomes approved (automatically or by Champ).
  • Screen-enforced like approval. A database rule can come later.
  • Data: anf_pos gets emergency_by, emergency_reason, emergency_at (one small migration).
