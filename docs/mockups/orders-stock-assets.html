RECOMMENDATION · SUPPLIES vs ASSETS

  • A fixed “Kind” field, not a tag. Supply and Asset behave differently (qty vs individual units, re-order vs location tracking), so the app needs one clear value it can rely on — tags can be missing, duplicated or misspelled.
  • Keep Category underneath as today (Paper, Ink, Sleeve… / Computer, Camera, Light, Router…), editable by admin.
  • Tags can still be added later for free-form labels (e.g. “fragile”, “CAP*TURES kit A”).

RECOMMENDATION · ASSET ID & LOCATION

  • ID = category prefix + running number: CAM-001, LGT-004, PC-003, RTR-002. Short, readable aloud, prints well as QR/barcode. Never re-used, even if the asset is retired.
  • Location = zone + slot: R1–R3 (rack, optional shelf A/B/C) · F factory · EV1–EV3 event kit slot, optionally linked to a Won job #. Plus states REPAIR / LOST / RETIRED.
  • Every move is logged (who, when, from → to) so “where was CAM-002 last week?” has an answer.
  • QR later: the QR just encodes a link like sx-crm.vercel.app/a/CAM-002. Scanning opens the card with a one-tap “Move to…” — no extra hardware needed, any phone camera works.

RECOMMENDATION · SUPPLIERS

  • Separate Suppliers list, linked to items (one supplier → many items; one item → several suppliers with one preferred).
  • Per link: price, unit, lead time, min order, how to order, note. ＋Order pre-fills the preferred supplier.
  • Admin edits suppliers; staff can see them so anyone can re-order.
